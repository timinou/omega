Verified 2026-10-04 on this host (kernel 7.0.14, Landlock ABI 8, OTP 29), spikes/beam-jail.bl.md.
- A ~190-line C exec wrapper (fork → Landlock --rw dirs → seccomp filter with NEW_LISTENER → pass the listener fd to the parent via SCM_RIGHTS → exec) run as an Erlang port gives BEAM every write-open/rename/unlink/mkdir/exec/connect of a whole process tree (python via sh, sed -i) as a line BEFORE it happens; BEAM answers allow/deny.
- NEVER enforce path policy with notify alone: a thread-flip TOCTOU let 724–747/3000 outside writes through although BEAM denied every outside path it saw; with Landlock as the floor, 0/3000.
- Cost ≈70–135 µs per notified event; reads/compute unmeasurable. Put build dirs in an in-BPF allow.
- io_uring is enabled here: filter io_uring_setup → EPERM. A pre-opened fd stays writable (Landlock checks opens): close fds ≥3 before exec.
- A whole jailed BEAM node: peer:start with exec => {wrapper, ["--rw",…, cookie-file, "--", "/usr/bin/erl"]} and JAIL_ONLY=1; from the bl VM first erlang:set_cookie to ~/.erlang.cookie, and use /usr/bin/erl, not the drop erts on PATH.
- Relay's earlier "Landlock needs a hook BEAM's open_port lacks" objection is answered by making the wrapper the port program. ora/spell PLAN-305 (FUSE mediator) was never built.
