#+title: What the latency measurements establish
#+status: Final pinned native, server, local, browser and Worker acceptance recorded

* Reproduce
Use the optional local generation printed by build/local!, then run from Omega:
#+begin_src sh
PELAGIC_LOCAL_OUT=/absolute/path/to/local-generation python3 spikes/pelagic/test/cutover-benchmark.py
PELAGIC_LOCAL_OUT=/absolute/path/to/local-generation python3 spikes/pelagic/test/compute-pool-browser.py
#+end_src
These scripts own temporary HTTP servers and browsers and close them afterward.
They do not touch the world on 8790. The root-task proof uses private XDG state,
a disposable store and a random port. No existing user realm is stopped.

* Protocol
The paired test warms the score and compiler, starts continuous transport and
runs five repetitions per absent/paused/active upstream browser reader. Order
is counterbalanced. Each trial has one second warmup, at least four seconds of
measurement and an identical 0.25-second, 22050 Hz offline audio render. Raw
heartbeat and RAF intervals are retained, plus export duration, scheduler misses,
long-task deltas, per-trial estimated JS heap and aggregate renderer CPU. This
measures upstream sampling without inspector DOM. Separate browser journeys
verify the actual inspector DOM and companion layout. The development machine
also runs unrelated services; these measurements are not a lab isolation study.

* Recorded ranges across five trials
| Reader | Heartbeat P95 ms | Frame P95 ms | Export ms | Missed scheduler events |
|--------+------------------+--------------+-----------+-------------------------|
| absent | 8.9–16.6 | 16.7–16.8 | 21.0–61.7 | 0 |
| paused | 8.7–11.9 | 16.7–16.8 | 31.2–38.3 | 0 |
| active | 9.1–14.0 | 16.7–16.8 | 28.3–40.0 | 0 |
Heartbeat includes the timer's requested 8 ms period; it is not response latency.
RAF includes display cadence. Scheduler misses are application counters, not
physical audio underrun measurements. No acoustic/display latency was measured.
The earlier 71638f46 baseline reached 33.3 ms frame P95. The final run
reached 16.8 ms. Different runs on a shared development host do not establish
a causal improvement; the raw baseline remains available.

The graphics Worker's retained rolling frame P95 is 30–37 ms across these
trials, while its reported graphics work P95 is 0.3–0.3 ms. These are rolling domain
counters, not per-trial compositor or physical-output measurements. Their clock,
queueing and headless rendering behavior need separate profiling; the main-page
RAF result must not hide this slower graphics cadence.

* Worker evidence
The canonical compiled Worker completes two identical 1024-row scores, 100 lease
reuse/cancel cycles and independent simultaneous sessions. A deliberate native
Worker error after importing the compiled kernel is followed by healthy
reacquisition. Cancellation P95 is 4.2 ms, main-thread heartbeat P95 5.1 ms.
No forced reset and no retained Worker remain after cleanup. Final-owner unload
also retires a resetting Worker after acknowledgment, preserving a live peer.

* Build evidence
The final clean compiler pin is =25f5e799=, installed as =7e72e86a=.
Its one-time clean release build took 9 min 18 s. The final full graph and local
ZIP build took 3 min 9 s; reuse of that graph plus local/ZIP work took 1.636 s.
An asset-only frontend refresh took 1.471 s. Cold root-task startup with a new
conservative full graph took 206.430 s; that is not a warm-launch result.
Root tasks reuse immutable generations and one shared VM. Unknown dependencies
remain conservative. Local is optional packaging of the same implementation.
The final local/browser and Worker benchmarks use generation =84ef8d29…=;
recordings retain their own actual source-bound generations.

* Dense canonical actor projection — an explicit regression
Five fresh Node processes each read 128 projected rows from 129 actors, after
20 warmups, with 100 measured queries. Query P95 ranges from 52.8 to 67.5 ms.
The 8 ms heartbeat P95 ranges from 24.0 to 28.8 ms, with maximum gaps
133.0–165.7 ms. Heartbeat covers import, bootstrap, warmup and measured work;
its maximum cannot be attributed only to the measured query. Raw samples,
fixture/compiler identity and canonical host hashes are retained.

The earlier 0.64 ms figure belongs to the removed experimental direct projection
emitter. It is not the final canonical kernel's performance. A separate initial
uninstrumented diagnostic reached 101.4 ms query P95 and is also retained;
it is not paired with the instrumented runs. Correct consolidation is complete,
but this dense workload misses 16 ms substantially. Profile common-core/frame
dispatch and root scheduling slices in a dedicated latency session. Preserve
one execution model; do not revive the deleted emitter as a fast fallback.

* What to investigate next
Profile the frame tail under export and observation, separating main-thread
work, Worker queue/turn time, GPU submission and compositor cadence. Compare
inspector DOM sampling with the upstream-reader trials. Then measure real
speaker/display latency on the intended device before claiming a 16 ms result.
Compiler cost/termination/purity fields remain explicitly unknown until stronger
analyses exist; non-suspension alone must not choose a deadline or thread.

* Root launch regression discovered during acceptance
The real Pocket root-task journey initially failed before presenting its first
question: a task executor could not resolve =omega.actor/sense-inbox= after a
DynamicSupervisor started it from an older environment. A focused upstream
regression reproduced the ownership loss. The fix captures the child-spec
creator's bindings and reuses them through OTP restart, restoring the caller's
bindings afterward. The strengthened regression has ten assertions covering source and installed
host, including a real killed-child restart. The actual final root-task/browser
journey also passes; focused unit results alone were not accepted as proof.

* Final acceptance and provenance
131 native Omega assertions, 80 editor/Runtime Node tests, 69 Pelagic Node
contracts and 20 Pocket drive tests pass. The unchanged presentation checker
passes 11 welcome and 12 Pelagic variants. Actual browser acceptance covers
15 inspector checks, 15 offline/local checks, five creative workflows, Pocket,
the shared root launcher and two independently audible server/frontend sessions.
Worker proof repeats 100 leases, two 1024-row scores, crash/reacquire and final
zero retained Workers. Cancellation P95 is 4.2 ms; heartbeat P95 is 5.1 ms.

The clean release provenance includes matching seeded/installed supervisor
bytes. Main-workspace browser proofs also include pre-existing concurrent
Pocket/workspace changes; those source changes are not part of these commits.
Software probes report no physical underrun/output latency. GPU timing is
unavailable in this headless run and the silent onset probe collected no samples.
The broader workload matrix, isolated inspector DOM overhead, total Worker CPU,
and real-device latency are measured follow-ups, not completed guarantees.
