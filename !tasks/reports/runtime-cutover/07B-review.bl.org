* Open the real instrument
From Omega's root use =bl pelagic.dev=. =bl spikes.pelagic.dev= opens the first
showcase. Both attach to the shared project world and reuse its immutable frontend.
For a static demo use =bl pelagic.local=; that is optional packaging of the same
editor/package graph, without a world API. Check the printed URL and generation.

* Capture → fork → audition
Choose PERFORM and evaluate the live set. CAPTURE TAKE starts an account of the
current session and document. Move FILTER, then FINISH TAKE. SAVE TAKE exports
the bounded manifest; REPLAY restores its base and clocked checkpoints. FORK
SOURCE opens the final state as an editable av/commit block. One undo restores
your previous source. Transport discontinuities or capture overflow invalidate
reproducibility explicitly; recorded media can still be kept as a partial take.

Choose AUDITION CODE to hear a quiet, separate monitor. The active model and its
history do not change. DISCARD PREVIEW closes that monitor. COMMIT AT BAR adopts
the proposal at a musical boundary. An intervening edit makes it stale.

* Explore → navigate → share
EXPLORE derives four choices from a seed and the current base. Selecting a choice
previews it through the same safe audition path. It does not apply a variation.
REVISION SOURCE brings back code that produced the active committed revision.
A static bundle can be shared alongside a take manifest; imported audio remains
content-addressed and must be relinked on a machine without those assets.

* Inspect without interrupting the stage
RUNTIME opens the companion layout. Ownership, Active work, Health & timing,
Builds & revisions and Selected item share the reusable bl-ed inspector.
Native resources follow their realm owners. Browser reports describe local
owners and expiring peers; a peer report grants no remote control authority.
Compiler evidence belongs to the immutable source generation. It is loaded once.

* Recorded timing, with limits
The final fifteen counterbalanced trials report zero missed scheduler events.
Active-reader heartbeat P95 is 9.1–14.0 ms; page-frame P95 is 16.7–16.8 ms.
These trials measure sampling without inspector DOM. Separate private browser
journeys exercise actual DOM retention and companion engine identity.
Dense canonical projection is slower: query P95 is 52.8–67.5 ms across five
runs. Graphics cadence and physical speaker/display output remain separate
latency investigations. No recording certifies a 16 ms physical response.
