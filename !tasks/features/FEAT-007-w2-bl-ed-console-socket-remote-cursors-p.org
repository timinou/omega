* Goal

The second, coloured cursor, live in bl-ed (§5.2, §6, §9). `ed.lisp` is deleted and `:` evaluates on the BEAM (§10.2).

* Scope

- Socket vocabulary up `[:op] [:attend] [:intent] [:eval]`, down `[:buf/op] [:buf/cursor] [:buf/marks] [:view] [:stream] [:suggest]`; views, not facts.
- bl-ed `host.mjs` gains one WebSocket.
- Remote cursors and selections (actor colour + label) and ghost text as decorations.
- Attention: ephemeral conn, symmetric human/agent, decay (typing 3 s, looking 10 s, agent editing 60 s), ≤4 Hz reporting, privacy toggle `space a .`.
- Agent edits overlapping fresh human attention park as suggestions; `y`/`n`; the agent's call returns `{:pending :suggestion}` before its deadline (E1).
- `:` sends form + editor value; `ed.lisp` removed; a BL value reader/printer in `rt.mjs`.

* Acceptance

- A scripted agent edits a file open in bl-ed; its cursor and text appear live.
- Looking at the region parks the edit; `y` lands it.
- `:` evaluates real Beam Lisp.
- `ed.lisp` is gone and the selftests are green.
- Measure `:` round-trip latency.
