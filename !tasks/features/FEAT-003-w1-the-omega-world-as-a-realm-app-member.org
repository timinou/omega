* Goal

One world per realm, sole owner of `.omega/db`; every runner attaches (§8.2, E3, E19). Agents' file I/O goes through a seam omega owns (§5.6, C6, E13).

* Scope

- `omega.world/world!`: idempotent per realm; `vm.manager/serve` role `:omega`; opens the durable env with extensions' `:schema` (C1), starts the system, `recover!`, registers in `proc.reg`, claims route `omega`.
- Idle exit: stop after `:omega {:idle}` (default 1800 s) with no running/waiting task and no console; next runner restarts it (§8.5).
- **C6** `prelude/read|write|edit` call `(:files sys)`; default port = today's disk functions.
- **C7** `omega.cli` attaches to the realm's world when warm, cold otherwise; on `:store-already-open` say 'a world is running; attach with --warm'.

* Acceptance

- `bin/omega "goal"` in a terminal and a REPL client in the same realm see the same task live; `bl realm` lists `omega` as a member; `bl realm stop` drains it.
- Kill the world mid-task; the next `bin/omega` restarts it and the task resumes from the store.
- With the default port, the suite is unchanged; with a test port, `read` returns the port's text.
