* Goal

Rungs 2–3 of the consensus ladder: agents perceive each other before colliding and settle contention by a visible tiebreak (§5.4, E2, E14).

* Scope

- `read` through the buffer port returns fresh edit marks (agent attention).
- After ≥2 overlapping CAS failures in a window, a `:contention` trace naming both tasks, the region and the cells; the convention that the older claim keeps the region (one system-prompt line).
- Persisted contention escalates to the human (both cursors red).
- The `:context` hook adds one attention line when scope overlaps.
- 'Written blind to each other' as a valid-time query.

* Acceptance

- Two scripted agents racing for one function settle without a human: the older claim's edit stands, and the other waits or messages it.
- The trace is visible on both cards.
