* Goal

The slice as a human sees it (ux-slice §2.1–2.6): ✦ gutter mark, one-line card drawn in place of the `#omega/task` result row, contextual `y`/`n`/`RET` answers (E27), the §3.3 evaluation table, `:` commands.

* Scope (beam-lisp `apps/bl-ed`; console code in `ed/omega.bl`, E28)

- `ed/omega.bl`: the evaluation table (open / focus / refine with goal digest / new task with `:prev`), card model from rows, `(omega/tasks) (omega/open g) (omega/say id text)`.
- `ed/main.bl`: events `:tasks {id → row}` and `:task-opened {:block-id :id :goal}` (writes the identity result via `bl.doc.spans/write-results`); terminal rows rewrite the result ONCE with `:status :summary :touched`; render: `:card` on a result row whose value is `#omega/task`, `:place "agent"` on a task block's first row; status line `⚑ n` for open asks.
- `ed/keymap.bl`: card-row contextual keymap merged into `km/keymap-of` (`y` `n` `RET`); `y` yanks elsewhere.
- `web/host.mjs`: effects `:task-open :task-say :task-answer :task-watch` (1 s poll only while a card is visible or an ask is open); card drawing; tones shared with omega `ui/theme.bl STATUS`.
- `serve.bl`: `/api/omega/*` forwards to `OMEGA_URL` or `<BLED_ROOT>/.omega/url`; `/api/place` marks task blocks `agent`; `/api/save` takes a `base` hash and answers 409 *changed on disk* when it differs.

* Edge

- No omega world: dimmed ✦ with the `bin/omega serve` hint; C-Enter shows the same message, writes nothing.
- The card replaces only the DRAWING of its row: motions, folding and byte-for-byte round trip unchanged (the existing round-trip test must still pass on all .bl.org files).
- A terminal rewrite happens only if the console has the file open; otherwise on the next open.

* Acceptance

- `drive.test.mjs` cases with a fake bridge: open → card running → ask → `y` answers → done → result rewritten once; `y` outside a card yanks; save with a stale base is refused with the message.
- `ed.selftest` green on BEAM and JS.
- Real run (S5): a human opens, answers and finishes a task in bl-ed; `apps/bl-ed/proof/10-task-card.png`.
