* Goal

History per tool step behind a backend-free protocol, so jj is replaceable by beam-lisp native history. The contract suite is what teaches the autovcs redesign (§5.9–5.10, E6, E17, E18).

* Scope

- `omega/vcs.bl.md`: `History` protocol (`checkpoint! changes tree-at diff abandon!`) plus the checkpoint policy as an omega extension (on `:step/end` from C5): trailers `Omega-Task`/`Omega-Cell`; the gate before describe; on gate failure checkpoint anyway as `[gate ✗]`, leave a `:finding` trace and turn the card line red (E18).
- `omega/vcs/jj.bl.md`: `JjHistory` over beam-lisp `vcs.jj`.
- `omega/vcs/native.bl.md`: `NativeHistory`, datom + `:db.type/file` (spike 3).
- `omega/vcs/test.bl.md`: ONE contract suite run against both backends.
- Facts `{:jj/change :jj/commit :jj/op}` (or backend-neutral `:history/change`) on the step.
- Shared working copy (E17 a); split by per-actor paths when disjoint.
- Upstream to beam-lisp `vcs`: `checkpoint!` takes `:trailers` and returns ids; `mirror!` optional/lazy/paged; daemon hook re-seated on realm `vm.session/dispatch-command`.

* Acceptance

- The contract suite is green on both backends (the spike's assertions: no-op checkpoint = nil; query by actor and by path; abandon keeps other tasks' work; a second abandon → `{:conflict paths}`).
- A 3-step scripted task produces 3 jj changes with trailers.
- 'what did t-N change' is one query.
- A failing gate produces a `[gate ✗]` change plus a finding.
- Measure the per-step cost on omega (the 0.2–0.6 s figure in §5.8 is INFERRED).
