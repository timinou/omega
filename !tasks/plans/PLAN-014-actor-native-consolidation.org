* Objective and authority
User requests actor-centered consolidation upstream, complete Omega/Pelagic
migration, readable BL modules and explanatory documentation, commits throughout,
and recorded demonstrations of all five experiences (especially safe audition).
Latency regressions may become explicit focused follow-ups; semantic regressions
and parallel production implementations are not acceptable completion criteria.

* Invariants
- One source reader, checked ANF, native-expression emitter, value contract,
  package linker and actor execution model. Direct non-suspending calls are an
  optimization of that model, not a competing runtime/profile.
- Preserve existing language collection/numeric/error/callback semantics.
- Remove old implementations after migrated consumers and differential checks
  pass. Temporary migration adapters are named, bounded, and tracked here.
- Omega packages remain pure state/effects, layered layouts, exact unload.
- Never write to the running user world. Preserve unrelated concurrent edits.
- One capped BL VM at a time; inspect scripts/bl-mem, stop owned processes.
- Do not claim physical 16 ms latency from headless or median-only results.

* Initial findings
Actor host owns a separate KW/Cons/Vec/map model and generator machine; sync
rt.mjs/abi.mjs implement a broader collection/numeric/callable ABI. Deleting one
without migrating its consumers loses semantics. Native interop already shares
js.emit/emit-native, but native links are still package-specified. Pelagic's
ordinary bundle still builds the synchronous editor graph and optionally copies
an actor artifact. Therefore optional actor preparation alone is not consolidation.

* Consolidation design decision
Actor control and canonical language values are separate responsibilities. Keep
one actor generator/frame machine and BL scheduling policy; reuse the richer
canonical rt.mjs value leaves and compiled BL core semantics. Direct host callbacks
will be checked, non-suspending entrypoints into that same machine, not a second
emitter/runtime. The legacy actor collection prelude must disappear once its
scheduler uses the compiled common core. Production artifacts must bind both paths
to the SAME value-module URL, not copies with distinct keyword caches/classes.

* Next compiler integration gates (stage 3 refinement)
Do these in dependency order, preserving the existing checked IR and semantics.
- Shared pattern lowering, reader-node access, identifier/string emission. Current
  candidate is in /tmp/actor-numeric-consolidation; not yet upstream. Fixtures
  cover exact numeric literal matching and missing-versus-present-nil fields.
- Move namespace declaration/staging/macro-helper discovery into one compiler
  preparation API. js.actor still has defn-only staging and procedure declaration
  expansion; js.build owns full ordinary defs/macros/initializers. They must use
  one preparation API before actor output can replace the ordinary frontend.
- Emit namespace-qualified callable bindings and initializers from checked defs;
  retain one module table/runtime identity and compiler-owned module contracts.
  Actual JS operations stay inline in annotated namespaces. An annotation alone
  is not a proof that a BL-to-BL call cannot suspend.
- Compile common rt/core through actor lowering; replace actor/runtime.bl's
  duplicate collection prelude with imports only when higher-order and bootstrap
  differential gates pass. The actor policy remains BL and the engine remains
  the only frame evaluator. Do not keep a sync/actor profile selector.
- Unknown higher-order calls require frames initially. Add conditional callable
  contracts for argument/capture requirements as direct specialization of the
  same IR, with runtime evidence owned by the compiler; never infer safety from
  an arbitrary JavaScript function's shape or author annotation. This avoids
  falsely promising a synchronous callback for a possible receiving function.
- Migrate evaluator output, editor event entrypoints and build tasks together;
  test cold/warm parity, native callbacks, package unload, exceptions, bootstrap
  cycles and user-defined functions before deleting the old control emitter.
- Protect compilation/analysis/export through actor job admission and generation
  cancellation. Worker-only async Promise queues are still a migration target;
  preparation's actor conversion does not complete evaluator CPU preemption.
