#+TITLE: Optional local PELAGIC compilation
#+DATE: 2026-10-08
#+STATUS: complete

* Scope
Build a self-contained static PELAGIC + real bl-ed application. The compiler,
reader, editor, package, shaders and patch ship together; no Omega world or
BEAM server at runtime. Keep Omega's normal compiler pin/build untouched.
Use a PELAGIC env.bl task, not a new task language or generic package builder.

* Implementation
- Separate compiler pin 26073421, one JS compilation and isolated output.
- Annotated pelagic.browser owns conversions and browser utility IO; pure
  pelagic.bridge owns live namespace bindings. Retain native DSP/GL engines.
- Generic optional document services in the real editor host; local IndexedDB
  documents with atomic revision checks, recovery and revision history.
- Bundle boots the SAME bl-package through ed/pkg and frame layouts.
- Offline asset cache; no remote dependencies; optional static HTTP hosting.

* Proof
Package and vendored-editor drive tests, unchanged presentation equivalence,
static browser drive with /api requests prohibited, live BL evaluation, sound,
save/reload recovery and exact unuse screenshots. No port 8790 writes.
