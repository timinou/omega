* Built (commits d161ee7, 004d413)
** Codemode
- =omega.codemode= provides one tool, =eval=, over =harness/eval-cell=. Each task gets its own namespace. A beam-native heap cap (=max_heap_size= with =:kill=) and a deadline mean a runaway allocation kills only that eval.
- =omega.prelude= holds the functions the code calls: =read write edit ls glob sh spawn wait send done trace traces q=. The task context comes from the cell process dictionary.
- The cutover is complete: =omega.tools= is deleted, and tests, the playground and the domain doc are migrated.
- Verified live: Sonnet 5.5 wrote two files and ran pytest in ONE eval.

** UI
- =omega.ui.model= projects the env, grouping tasks by urgency.
- =omega.ui.theme= has dark and light themes, tested to WCAG AA, with status shown as glyph + word + tone.
- =omega.ui.screens= (.bl.md) is an overview with a composer and in-place answers, plus a task screen.
- =omega.ui.desktop= folds env commits, page events and a 1 s tick through one reducer that calls only public verbs.
- Entry points: =bin/omega-ui=, plus =bin/omega-shot= for agents to see the UI.
- Verified by driving the real window with =wtype= keystrokes and a JS click: typed goal → live task → files edited → done, all shown in the window.

* Defects found and fixed along the way
- beam-lisp BUG-109 (filed in the beam-lisp repo, untracked): a qualified call to a project fn that shadows a core name runs CORE on the first cold call. =omega.loop/run!= returned nil on every fresh VM, so it was renamed =turn!=.
- The executor now treats outcomes as total: a non-outcome becomes =:failed= with its reason, and failures record =:task/result= plus a =:blocker= trace.
- =:task/cost= was never accumulated (a wrong key); fixed and tested.
- Window input: page events arrive nested (=[[:k a] v]=) and are now normalized. Drafts live outside the rendered state. loom's body swap lost text typed during a render (0/3 → 3/3 after a client-side patch). Candidate upstream fix: =SWAP-KEEPS-TYPING= in =omega.ui.desktop=.
- =sh= runs with =TERM=dumb NO_COLOR=, so no terminfo noise reaches the model.
