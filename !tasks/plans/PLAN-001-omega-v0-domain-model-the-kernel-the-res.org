* Build order (v0)
1. =src/omega/schema.bl=: the datom schema as data, plus a glossary (attrs, trace kinds).
2. =src/omega/env.bl=: open the environment (conn), transact helpers, queries, watch → mailbox wake.
3. =src/omega/actor.bl=: actors (tasks and humans) with mailboxes; send/inbox as facts plus a process wake.
4. =src/omega/task.bl=: the public interface (new, say, steer, cancel, await, status, children), with the executor as a =defserver= under a DynamicSupervisor. Owner edges; cancel cascades down, and failure/cancel bubbles up.
5. =src/omega/loop.bl=: the model step seam (=:step= fn) → tool calls → results; a scripted model for tests.
6. =src/omega/tools.bl=: read, write, edits[], bash, eval (harness-style beam-lisp cell), spawn-task, send, wait.
7. =src/omega/llm.bl=: the Anthropic messages client (via the proxy) behind a provider map, plus a cassette seam.
8. =src/omega/ext.bl=: hooks/events (call-predicate, context-transform, turn-snapshot, plus the minimal event set).
9. =ext/notify.bl.md=: a desktop-notification extension built on the surface (literate).
10. =omega.bl.md= / =bin/omega=: a runnable demo you can try (scripted offline, and live with the proxy).
11. Tests in =test/= covering the domain behaviour.
