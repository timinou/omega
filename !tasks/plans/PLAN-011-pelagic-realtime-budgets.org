#+TITLE: PELAGIC audio/video deadline architecture
#+DATE: 2026-10-09
#+STATUS: implemented; strict end-to-end deadline target open

* Objective
Target a 16 ms p95 work/submission budget and smooth display-paced frames while
protecting audio deadlines during editing, scene transitions and recording.
Measure frame interval separately: a 60 Hz display supplies 16.67 ms periods.
Retain strict measured values and report misses; never hide stalls by resetting
histograms, excluding stressed intervals or substituting CPU time for pacing.

* Optimization candidates, in implementation order
1. Remove the explicit 30 Hz visual throttle. Keep DOM telemetry at a lower rate.
2. Profile playback, transitions, editor input, compilation and recording on the
   current static bundle; measure CPU service time, cadence, audio probes and AV.
3. Sample audio analysis once per frame; reuse typed buffers, uniform locations
   and texture storage; avoid redundant feedback copies and unused scene passes.
4. Render WebGL in an owned OffscreenCanvas worker where supported. Keep one
   latest frame in flight, bounded queues, transactional shader preparation,
   context recovery, capture and deterministic disposal. Preserve a fallback.
5. Drive visual phase from audio output timestamps, with explicit freshness and
   clock-origin mapping across realms. Distinguish submission from physical AV.
6. Isolate score preparation from UI stalls using compiled BL policies and an
   audio-clock scheduling buffer. Preserve quantization and atomic revisions.
7. Use native/JS lowering and typed/system logic for proven hot functions;
   specialize stable shapes and keep optimization decisions behind existing APIs.
8. Pressure-test continuous performance, transitions, recording, large live edits,
   stale/reordered messages, worker failure and unload. Commit each validated slice.

* Scope and ownership
PELAGIC remains a real bl-ed package. Audio/DOM resources stay host-owned;
workers have explicit lifetimes and bounded messages. No writes to the user's
world on port 8790. Use isolated static or offline-memory test servers only.
Preserve unrelated dirty files. Upstream generic compiler/runtime improvements
are committed independently; source pins remain reproducible.

* First validated slice
Removed the 30 Hz cap; master analysis and its GPU upload are shared by layers.
Feature calibration uses bounded cached lookup tables; bus level meters read
waveforms without unused FFTs. GPU locations and texture allocations are reused.
31 package tests pass. A 45-second profiled transition/edit stress run improves
frame p95 164 -> 125 ms, missed scheduler steps 9 -> 0, and sample-onset maximum
66.67 -> 0.022 ms on this busy host. These runs are profiling evidence, not the
final frame-budget gate. The 16 ms target remains open; isolation follows.

* Worker and BL policy slice
Owned OffscreenCanvas rendering has a bounded latest-frame mailbox, explicit
absolute performance-clock stamps, failure watchdogs and transport suspension.
BL policies project time, select fresh audio output timestamps and adjust internal
resolution with hysteresis. A bounded per-host BL cache reuses converted immutable
score graphs; mute/config behavior is checked against the original score.
Steady single-layer scenes bypass compositing; DOM telemetry runs at 10 Hz.
34 package tests and the real performance drive pass, including shader rejection,
1280x720 recorded video (ffprobe), GPU recovery and exact unuse. Keep strict
submission acknowledgements distinct from earlier handoff-only worker timings.

* Sustained pressure finding
The first 300-second run stopped at its second injected UI stall: cached host
telemetry advanced only one frame over the stall/probe interval. This is retained
in proof/realtime/raf-pressure-failure.json, not counted as a successful soak.
Use a read-only worker counter for stall checks. Add generic compiled BL js.frame
pacing that races RAF against a one-period timer, cancels the loser, and supplies
an opaque cancellable handle. Preserve deadline failures as evidence.


* Native clock and allocation slice
Generic js.frame is committed upstream (7861aa54), pinned via 341ca18d.
Native worklet-to-renderer clocks have one packet outstanding per subscriber,
with eight subscribers maximum. GPU timers are asynchronous and bounded to four;
quality follows GPU cost instead of reducing resolution for editor/OS stalls.
Native audio reserves four seconds independently of the 1.15-second revision
preparation horizon. Pure BL audio-equivalent? preserves those reservations for
visual-only edits. This removes redundant graph reconstruction; native cancellation
stops sources immediately and retires disconnections in bounded batches.

40 package tests and 22 native JS checks pass. A proposed native envelope fusion
failed waveform equivalence and was reverted; retained DSP passes the reference
render. Recording preparation now waits for submission, retrying mailbox-replaced
frames instead of starting capture at the previous canvas dimensions.

Failed pressure runs remain under proof/realtime: short audio reserves, insufficient
edit preparation, needless audio rebuilds, and early capture are recorded separately.
The last pre-capture-fix 300-second run had zero missed events, 5.3 ms worker CPU
p95 and 2 ms GPU p95; cadence 21 ms and AV submission 42 ms still miss target.
Its audio sample-onset maximum was 397 ms despite a 0.021 ms p95; native audio
advanced at 0.769 of wall time on this heavily loaded host. Do not claim physical
AV or a strict end-to-end 16 ms guarantee from these results.


* Final validation
The capture-fixed 300-second run passes functional pressure gates: 30 revisions,
zero scheduler misses, actual 1280x720 VP8/Opus, independent worker progression
through both UI stalls, shader rejection, worker failure transport stop, source
preservation and exact unuse. Worker CPU p95 is 6.1 ms, GPU p95 1.9 ms at full
quality. Cadence p95 22 ms and native-clock-to-submit p95 21 ms miss the target;
main acknowledgement p95 is 642 ms. Sample-onset p95 is 0.022 ms but its maximum
is 320 ms; three native graphs completed after start. Native clock rate is 0.776
of wall time. Preserve these failures rather than equating zero scheduler misses
with glitch-free audio. Concurrent browser contract checks also ran in this interval.

Latest 19 performance-browser and 14 static/offline browser checks pass. Package
40, upstream native JS 22, vendored editor 73 and unchanged presentation 23 pass.
The reproducible 44-module bundle and ZIP integrity check pass. Current evidence
is spikes/pelagic/proof/realtime/report.json; screenshots cover used and unused
real editor states. Further strict latency work needs profiling on a controlled
realtime-capable host and physical AV loopback; the 16 ms target stays explicit.
