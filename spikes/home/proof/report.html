Browser proofs include existing concurrent Pocket/workspace edits, preserved outside these commits. These are functional proofs; no physical audio/display latency is certified.

Native findings

WebKit exposes OffscreenCanvas but cannot create the required Worker WebGL context here. Pelagic checks the real context before transferring its canvas and uses the same renderer in the window when necessary. Native audio activation, rendered frames and a non-silent offline export are exercised. Software graphics evidence does not certify the 16 ms target.

The native window runs in a narrow display process so WebKit cannot inherit the canonical host’s listening sockets. Upstream Wry now observes finished window threads and raises failures correctly. The shipping root launcher is tested through an actual window-manager close; the host remains available, and explicit stop closes its port without terminating the shared VM.
