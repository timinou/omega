#+title: Omega — a small door into the Lisp machine
#+date: 2026-10-13

* Start
From the Omega root:
#+begin_src sh
bin/bl omega
#+end_src
This opens the native workbench over the compatible durable world. Work is the
first buffer: your tasks, questions and answers. =-- --demo= uses scripted tasks;
=-- --browser= prints the same workbench URL. The window title is Omega.

* Work, then wander
Choose a task. Its conversation opens; desktop also keeps a following work list
on the left. Write a thought without sending it. Choose Buffers, then Pelagic.
Press PERFORM. Choose Work and reopen the task: the unfinished thought remains.
The instrument keeps playing. Switching a view does not restart its actor or
create another world.

Use Places for named environments, their actual directories and inherited
settings. New tasks use the selected place. A visible document is not silently
added to an agent's input: choose context or attach an explicit reference.

* Three small controls
The current title/place is a context control. The header's =⋯= opens contextual
Actions; =⌘= opens searchable Commands; =:= goes straight to Lisp. Dialogs own
focus until closed, then return it to the control that opened them.

In Commands, Open accepts provider addresses. Try =bl:= for namespaces, or a
real document such as =work:YOUR-PLACE/README.bl.org=. The target picker names
Work, Conversation or Document. Editor evaluates in that editor; Machine uses
the host evaluator. These are different targets, deliberately visible.

#+begin_src beam-lisp
(+ 1 2)
#+end_src

Actions come from the loaded packages' typed object capabilities. Inspect
source shows the same buffer's text. References opens actual saved relationships.
Confirmation prompts for changes belong to the editor; closing a sheet does
not silently confirm an operation.

* Find a working surface
Buffers includes open documents, recent objects, personal pins, the retained
Lisp session, namespaces, Pelagic and Runtime. Recent means visited; it does not
mean that every recent document has an independent live editor. The current
implementation retains one working-file editor and guards unpublished edits.

Runtime shows owned native actors and reported browser resources. Those are
separate observation trees; it never fabricates ownership of another process.
Pelagic's own RUNTIME button opens its companion without replacing playback.

* Leave, or inspect the frame itself
Closing the native window ends its local viewers/audio. The shared host and
accepted background work remain alive. Stop this world's host explicitly:
#+begin_src sh
bin/bl omega.stop
#+end_src

The ordinary editor still owns layouts, packages and keys:
#+begin_src beam-lisp
(ed/layouts)
(ed/unuse "home")
#+end_src
Use these in the editor's =:= prompt. Unuse removes the workbench's layers,
styles and child viewers and restores the underlying editor. Reopen =bl omega=
to enter the workbench again. =space h h= is the package's ordinary Work command.
