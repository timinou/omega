## Discrepancies and limits

- The model did not consistently respect requested 3–6 call limits. Sixteen-step
  and cumulative token guards, operator steers and separate follow-up tasks were
  necessary. This is not a claim of unattended flawless research.
- One broad grep stalled. Initial helpers assumed the wrong cwd; current tool
  descriptions and instructions now agree on the desk cwd. Runtime helpers are
  copied into each desk, and saved Beam Lisp is automatically preloaded.
- Shell quotes, bare accessibility refs and partial JSON arguments caused real
  failures. Literal arg-file helpers and malformed-call handling now avoid those
  infrastructure failure modes. Model-generated functions can still contain
  brittle portal selectors or range errors; the Morocco keyword discovery failed
  and the refresh report records it instead of inventing new notices.
- DeepSeek's documented thinking controls differ from `reasoning_effort`.
  The adapter now explicitly defaults thinking to disabled, configurable with
  BROWSER_THINKING=enabled and BROWSER_REASONING_EFFORT. Source:
  https://api-docs.deepseek.com/guides/thinking_mode/ . Empty/truncated responses
  preserve usage and execute no malformed tool call.
- A report initially claimed the dossier was acquired in the analysis run and
  used the wrong UTC date. The audit corrected provenance/date and retains the
  earlier artifact. A later audit corrected an overbroad Moroccan-registration
  statement: RC pp.5–6 and p.17 distinguish award-stage documents and foreign
  participation. Ora's actual bidding domicile and evidence remain unknown.
- The final model claimed it updated the narrative qualification report, but
  inspection found stale wording still there. Current structured requirements
  and generated `qualification-facts-onmt-qlik.bl.org` are authoritative for the
  desk; historical narrative and audit remain visible. This guard addresses
  synchronization, not the legal accuracy of model interpretations.
- Profiles save cookies/localStorage privately, not JS memory, drafts,
  sessionStorage or IndexedDB. Restored sessions start closed with login validity
  unknown. Headless observation, handoff and private storage were exercised;
  this host has no display, so no live headed Chromium switch is claimed here.
- Early world restarts reused task IDs and one run UUID. Individual generated archive summaries now preserve the separate costs; exact early page attribution remains uncertain.
- Explicit opens are counted, not every click-induced navigation. One provider
  response can overshoot a token threshold; the next paid request is blocked.
- Local execution is demonstrated. The existing browser provider boundary makes
  a remote Kernel adapter possible; it is not implemented or verified by this run.
