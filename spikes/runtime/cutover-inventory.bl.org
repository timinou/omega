The pool owns physical threads and routes actual Worker messages; BL actors
own logical jobs and bounded CPU turns. A pooled worker can serve two sessions,
so disposing session A must preserve session B's leases. Browser peer reports
carry descriptive data only; they do not extend native realm authority.

* Execution and logic audit
- Ordinary JS namespaces, evaluation and actor bundles use js.emit, actor/module.mjs
  and the same host frame kernel. The duplicate actor emitter/prelude, numeric gate,
  projection emitter and remote-map are deleted (upstream b410b1da). Imported receive
  resolves the caller’s existing process kernel (71638f46), preserving its mailbox.
- system.suspension proves non-suspension over checked IR. Unknown calls fail
  closed. Immutable host state/self reads are admitted; writes, critical sections
  and suspension/scheduler entrypoints remain excluded for callback evidence.
- That proof is separate from purity, bounded cost, termination, worker safety
  and physical latency. These facts must not be synthesized from one another.
- runtime.observation keeps active history before completed rows; proc.work
  bounds admission separately. Durable accepted effects still use existing
  proc.admission/queue, rather than this discardable private-work API.
- Native owner queries are paged before process projection (a7d140a7). Bounded
  subscriptions carry sequence/loss/resync metadata (34e41a54). Compiler evidence
  records source provenance and conservative non-suspension (48546571).

* Measurement protocol
Record compiler commit and artifact identity for every run. Separate cold
build, cached graph reuse and warm launch. Measure observation off/on during
playback, history churn, cancellation and shared-worker sessions. Report native
reductions/memory separately from browser timing. Record frame P95/P99 and
missed events; label submission/clock estimates separately from physical output.

Verified gates: 66 upstream BL assertions, nine compiled browser tests,
fourteen canonical ABI/callback tests; actor semantics/lifecycle fixtures and
11 OTP comparisons. Omega: 67 native/frontend assertions, 68 Pelagic contracts,
75 vendored editor tests, four Runtime drive tests, unchanged presentation
variants and twelve private real-browser lifecycle checks.

The real Worker fixture passes 100 reuse/cancel cycles and two complete scores,
with independent sessions and actual owned actor snapshots. It leaves no Worker.
Raw evidence is spikes/pelagic/proof/shared-compute/pool.json.

Historical experimental actor projection benchmark: 129 actors, 128 rows, 20 warm-up plus
100 measured reads. P95 falls from 172.08248 ms to 0.636692 ms using checked
closed-kernel direct lowering. Conversion, DOM and physical A/V are excluded.
Raw samples and environment hashes live upstream under docs/proof/runtime-observation.
