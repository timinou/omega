The request was to fix apparent hanging generation and interaction/DOM refresh
latency in the real workbench. Browser tests used an offline memory world on
8792. No writes were sent to the user's worlds on 8790 or 8814; the existing
shared host was not stopped or replaced.

Changes
- Native prompt typing no longer runs an editor transaction per character.
  A draft is synchronized after 250 ms idle and before blur, submit or Escape.
  Pending native text is retained across unrelated model updates.
- Bounded caches retain target discovery, musical component models and unchanged
  source line data. Cursor, status, errors, folds, placement/card/object changes,
  source edits and undo remain current. Pelagic slot geometry no longer depends
  on prompt text/history/progress or unrelated selection changes.
- Reveal checks an already-visible component using the existing slot geometry,
  without painting/coloring the document just to establish visibility.
- The inactive earlier melody-only presentation no longer recomputes for every
  workbench interaction. Explicit legacy requests retain stale-source protection.
- Inline native package views retain DOM identity when only row/selection
  styling changes. A reproduced one-line-form selection previously detached
  its component control; that control now remains connected.
- Generation shows elapsed time and supports cancellation. A network/body stall
  fails after 60 s. Browser checks have a 30 s deadline; thrown worker/check
  errors now finish the request with an inline error instead of a busy state.
