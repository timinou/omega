* Boundaries
Personal view state, drafts, pins, snooze and REPL history belong to this browser
tab and durable world, in sessionStorage. Task/turn/place/buffer facts belong to
the host and converge across devices. Clearing browser storage clears local
view history. There is no new task authority and no cross-device handoff action.

The reader uses the editor's canonical structural spans for document source
blocks. The host text renderer escapes all source/model text and formats common
Markdown/Org prose, headings, lists, tables, links and code. Arbitrary embedded
HTML is deliberately displayed as text. Recorded tool output is shown in full;
this cannot recover text the tool itself did not record.

Changes is attributed shared-buffer history, not a Git diff. Undo retains the
existing backend's revision/overlap safeguards. Home, plan, input and output
remain distinct; a scratch home is not presented as an inferred plan.

Directory browsing is over the trusted server filesystem and attaches existing
directories. Parent changes use the form's explicit directory; an empty local
cwd restores inheritance. Other config keys survive form edits.

This proof uses Chromium touch emulation and independent desktop/phone contexts.
It does not establish Safari/physical keyboard, VoiceOver/TalkBack, app suspension,
network handover or native notification behavior. Native wrappers, push and OS
selection-menu integrations remain later platform work, as in the approved review.
