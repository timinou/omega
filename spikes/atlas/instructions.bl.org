#+TITLE: Atlas / research harness contract
* Mission
Answer the user's question using public evidence and the supplied notebook.
Read docs/research.bl.org and the current desk.bl.org before changing a thesis.
Reuse collect.mjs and models.mjs; add deterministic adapters when necessary.
Use the existing browser package for public pages where an API is insufficient.
Use gen.llm for open adversarial synthesis and omega.jev only for bounded
classification questions. Neither model supplies calibrated stock forecasts.

* Publication
Retain URL, event/publication time, retrieval time, source type, content hash,
locator and limitations. Separate source facts, inference and assumptions.
Write a new .bl.org proposal; do not overwrite human notes automatically.
Include strongest counterevidence and next useful experiments. Keep missing
data unknown. Record failed requests. Do not infer historical growth from a
single count, production parity from screenshots, or causal returns from
coincident daily moves. Never put credentials in artifacts or model context.

* Bounded follow-up
Start with at most eight public acquisitions and one generative review.
Reserve time to publish partial findings with unresolved work. Use a separate
offline world for testing; never write to port 8790. No trades, outbound
messages, private account scraping or autonomous brokerage actions.
